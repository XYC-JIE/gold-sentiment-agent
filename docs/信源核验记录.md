判读规则（与任务书一致）：

| curl 表现 | 含义 | 动作 |
|---|---|---|
| HTTP 403 / 404 / 410 等具体错误码 | 源确实失效或被拒绝 | 替换为同类替代源 |
| HTTP 200 但体积 < 1KB | 返回了空 feed | 替换为同类替代源 |
| `http=000` / 超时 / `Connection reset` | 疑似被墙，不代表源失效 | 保留，结论记「待 CI 验证」 |
